# 剑网3 · 奇穴研习录

轻量的普通版奇穴模拟器，点击槽位选择奇穴，悬停查看效果说明。

[打开模拟器](https://xiaoyanqwq.github.io/jx3-talent-lab/)

- 32 心法，六层单选与混选池 12 选 3。
- 自动检查核心奇穴前置，更换核心时清理不再满足条件的选择。
- 纯 HTML、CSS、JavaScript，无需安装、登录或后端。
- 方案保存在当前浏览器，不进行云端同步。

## 数据版本

普通版「苍生铸世」测试服固定快照，以首轮完整表为基础，依次合并第二轮、第三轮公告；第三轮为准。不包含悟版与之后的热修。

1. [2026-09-08 · 首轮完整奇穴表](https://jx3.xoyo.com/mobile/gg.html?id=1335768)
2. [2026-09-24 · 二轮武学调整](https://jx3.xoyo.com/mobile/gg.html?id=1335822)
3. [2026-10-13 · 三轮武学调整](https://jx3.xoyo.com/mobile/gg.html?id=1335859)

离经易道「星移」按玩家校对置于第三层；分山劲「神威」暂按玩家推定置于第二层。校对依据可在页面的版本来源与奇穴详情中查看。

非官方爱好者工具。游戏名称、奇穴名称与效果说明归相关权利人所有。

## 本地运行

在此目录运行 `python3 -m http.server 8766`，然后访问 `http://localhost:8766/`。
